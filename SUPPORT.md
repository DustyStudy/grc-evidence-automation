# Getting help

- **Questions and how-to:** open a [GitHub issue](https://github.com/DustyStudy/grc-evidence-automation/issues/new/choose) using the bug or feature template. Include your Python version, where it runs and a minimal reproduction, with account ids and evidence removed.
- **Security vulnerabilities:** report privately through [GitHub security advisories](https://github.com/DustyStudy/grc-evidence-automation/security/advisories/new). See [SECURITY.md](SECURITY.md).
- **Scope:** this is a solo-maintained open-source project with no SLA. It gathers configuration evidence; it does not establish that a control is effective or that you are compliant, and auditors decide that. Read "What automated evidence does and does not do" in the README before relying on it.
